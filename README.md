# igra — PPO-агент для Minecraft 1.16.5 PvP

Полный стек: живой сервер Minecraft 1.16.5 (Node.js, протокол + физика Mineflayer),
два реальных Mineflayer-бота, браузерный 8-камерный 360° спектатор и PPO-политика,
обученная на **1 000 000+ живых боёв** в PRO-мете: кристаллы Края, respawn-якоря,
TNT-вагонетки, обсидиановые клетки, W-tap комбо, **выход из комбо и контр-комбо**.

## Что умеет агент

| Приём | Действие | Механика |
|---|---|---|
| Движение / спринт / прыжок | `1-11` | реальная физика, криты в падении, sprint-отдача |
| Щит | `12` | блокирует удары, ломается топором на 5 с |
| Золотое яблоко | `13` | Absorption + регенерация |
| Мгновенный хил | `14` | +7.5 HP |
| Эндер-перл | `15` | блинк к врагу / отход |
| Зелье баффа | `16` | Speed II + Strength (плюс +3 урона) |
| Дальний бой | `17` | снежки / яйца / арбалет / зелье вреда |
| Баррикада | `18` | блоки между игроками блокируют снаряды и рывок |
| Паутина / лава | `19` | обездвиживание и ожог |
| Ведро воды | `20` | тушит огонь, сбрасывает паутину, отталкивает |
| Pillar-jump | `21` | блок под ноги, преимущество по высоте и криты |

## Обучение

```bash
# 500 000 живых боёв (векторизованная арена, 1024 параллельных боя)
.venv/bin/python train_pro.py --fights 500000 --n-envs 1024

# локальный симулятор (старая мета, 24 obs / 22 действия)
.venv/bin/python train.py --mode sim --episodes 50000
```

`env/pro_vec_env.py` — PRO-арена: `Box(30,)` наблюдений и `Discrete(28)` действий,
vanilla 10-тиковые i-frames, асимметричные случайные лоудауты, броня и зачарования.
Противник — **скриптовый профессионал** (`ProArena._enemy_brain`): кайтит дистанцию
кристалла, таймит щит, ломает щиты топором, ставит клетки от взрывов, кидает перлы,
лечится, ставит ловушки и сам исполняет полные взрывные комбо.
Его сила растёт по ходу обучения (`set_enemy_skill(0.3 → 1.0)`).

## Живой сервер + спектатор

```bash
node bot/mock_server.js                     # MC 1.16.5 на :25565 + дашборд 0.0.0.0:8080
STEP_DELAY_MS=75 node bot/bot.js            # LearnerBot + профессиональный EnemyBot
.venv/bin/python play.py --mode live --model models/pvp_ppo_pro_500k.zip --episodes 300
```

Дашборд `:8080` показывает 8 камер 360° вокруг обоих ботов, полосу HP, щиты, броню,
поставленные блоки и живой лог боя (включая `💥 Explosion`, `⚡ W-TAP`, `🧱 OBSIDIAN CAGE`).

## Комбо-механика (второй этап, +500 000 боёв)

Добавлены две новые механики и два новых действия (`28` — выход из комбо, `29` — контр-комбо):

* Серия ударов по одной цели копит **цепочку**: каждый следующий удар бьёт сильнее
  (`+6%`, максимум `+40%`), а оглушённый боец не может ответить (`0.45 с`).
* Выход из комбо сбрасывает цепочку, даёт неуязвимость и открывает окно контратаки.
* Противник во время обучения специально «звереет» (агрессия 0.55 → 1.0), а 45% боёв
  начинаются сразу внутри цепочки — иначе учиться выходить было не на чем.

Результат финального прогона (501 207 боёв, 26.7M шагов):

| Метрика | PRO 500k (было) | COMBO FINAL |
|---|---|---|
| Выходов из комбо | 0 | **122 374** |
| Контр-комбо | 0 | **4 230** |
| Win-rate в бенчмарке | 76.8% | 74.4% |
| Выходов из комбо на бой | 0.00 | **0.57** |

## Результаты

* **500 694** живых боя за 24 минуты (~350–700 боёв/с), 20 447 232 шага PPO.
* Win-rate против профессионала вырос с **3%** (старт) до **88%** (последние 200 боёв).
* С комбо-механикой финальный прогон держит **74.4%** против уже усиленного
  (агрессия 1.0, 45% боёв начинаются внутри цепочки) противника.
* Итоговый бенчмарк модели, 400 боёв на каждый уровень скилла:
  `skill 0.30 → 80.6%`, `0.60 → 78.4%`, `0.85 → 77.7%`, `1.00 → 77.2%`.
* **Второй этап (+500 000 боёв)**: 501 207 боёв, 26.7M шагов — агент научился выходить
  из комбо (122 374 раза) и ставить контр-комбо (4 230 раз), см. таблицу выше.
* Живой сервер (12 боёв): **75.0% побед** (`9W / 3L / 0T`), MeanReward `66.3`, MeanSteps `55.2`.
* Приёмы в живых боях: `obsidian_cage 19`, `cobweb_trap 7`, `end_crystal 3`, `pearl_crystal 2`,
  `tnt_minecart 1`, `respawn_anchor 1`, `wtap_combo 1`, `pillar_jump 5`, `lava_trap 3`,
  `crossbow 4`, `buff_potion 4`.

## Поиграть самому (браузер)

Сырой порт Minecraft `25565` из песочницы наружу не пробрасывается, поэтому для игры
с человеком есть отдельная браузерная арена — тот же движок боя, что и в обучении:

```bash
.venv/bin/python human_server.py --port 8090 --model models/pvp_ppo_combo_final.zip --level normal
```

Открыть `http://localhost:8090` — вид сверху, кнопки действий и управление с клавиатуры
(`WASD`, пробел, ЛКМ/E, Shift, 1–9, **R** — выйти из комбо, **T** — контр-комбо). Ты играешь за второго бойца, нейросеть — за первого.

| Уровень | Что делает гандикап |
|---|---|
| Лёгкий  | у ИИ 12 HP вместо 20, и он действует через ход |
| Обычный | у ИИ 17 HP вместо 20 |
| Про     | без гандикапа — так, как она играла 1 000 000 боёв |

API: `GET /api/state`, `POST /api/action {"action": N}`, `POST /api/level {"level": "easy|normal|pro"}`,
`POST /api/reset`. Все 28 действий описаны в `web/play.html` (массив `PAD`).
