# igra — PPO-агент для Minecraft 1.16.5 PvP

Полный стек: живой сервер Minecraft 1.16.5 (Node.js, протокол + физика Mineflayer),
два реальных Mineflayer-бота, браузерный 8-камерный 360° спектатор и PPO-политика,
обученная на **1 000 000+ живых боёв** в PRO-мете: кристаллы Края, respawn-якоря,
TNT-вагонетки, обсидиановые клетки, W-tap комбо, **выход из комбо и контр-комбо**.

## Что умеет агент

| Приём | Действие | Механика |
|---|---|---|
| Движение / спринт / прыжок | `1-8, 10-11` | движение, атака, прыжок и отход относительно цели |
| Критический прыжок | `9` | прыжок без спринта и одна заряженная атака на падении |
| Щит | `12` | поднять щит из инвентаря/хотбара и отступать; блок зависит от угла/сервера |
| Золотое яблоко | `13` | употребить обычное/зачарованное яблоко из инвентаря или хотбара |
| Мгновенный хил | `14` | splash-зелье лечения на ноги игрока |
| Эндер-перл | `15` | к цели или, при отходе, в сторону от неё |
| Зелье баффа | `16` | Speed II + Strength (плюс +3 урона) |
| Дальний бой | `17` | снежки / яйца / лук / арбалет / зелье вреда; лук натягивается, арбалет сначала заряжается, затем выпускает болт |
| Баррикада | `18` | блоки между игроками блокируют снаряды и рывок |
| Паутина / лава | `19` | обездвиживание и ожог |
| Ведро воды | `20` | тушит огонь, сбрасывает паутину, отталкивает |
| Pillar-jump | `21` | блок под ноги, преимущество по высоте и криты |
| **Кристалл Края** | `22` | обсидиан + кристалл → взрыв и отход от своей зоны поражения |
| **Respawn-якорь** | `23` | только в измерениях, где якоря взрываются: заряд glowstone, активация, отход |
| **TNT-вагонетка** | `24` | активирующий рельс + вагонетка + редстоун-источник, затем отход |
| **Обсидиановая клетка** | `25` | стены вокруг себя режут урон взрывов на 65% |
| **W-tap комбо** | `26` | удар со сбросом спринта: меньше отдачи, комбо-урон |
| **Перл + кристалл** | `27` | блинк в упор и мгновенный подрыв |
| **Выход из комбо** | `28` | щит / вода / перл, сброс входящей цепочки |
| **Контр-комбо** | `29` | буферизованная контратака в окно после выхода |

## Обучение

```bash
# 500 000 живых боёв (векторизованная арена, 1024 параллельных боя)
.venv/bin/python train_pro.py --fights 500000 --n-envs 1024

# локальный симулятор (старая мета, 24 obs / 22 действия)
.venv/bin/python train.py --mode sim --episodes 50000
```

`env/pro_vec_env.py` — PRO-арена: `Box(34,)` наблюдений и `Discrete(30)` действий,
vanilla 10-тиковые i-frames, асимметричные случайные лоудауты, броня и зачарования.
Противник — **скриптовый профессионал** (`ProArena._enemy_brain`): кайтит дистанцию
кристалла, таймит щит, ломает щиты топором, ставит клетки от взрывов, кидает перлы,
лечится, ставит ловушки и сам исполняет полные взрывные комбо.
Его сила растёт по ходу обучения (`set_enemy_skill(0.3 → 1.0)`). Action 17 в симуляторе
отрабатывает полный цикл: лук выпускает стрелу после натяжения (1 с), арбалет тратит
болт на зарядку (1.25 с) и требует отдельного действия для выстрела; дальность и укрытия
проверяются, контакт стрелы/болта и расход боеприпасов идут в reward/метрики
`bow_hits` и `crossbow_hits`. Action 17 также сохраняет движение к цели вне ближнего
боя; признак 18 явно различает лук, арбалет, заряженный арбалет и активную зарядку.
Старт натяжения/зарядки и выпуск дают по `+4`, попадание — ещё `+8` reward;
`train_multi.py` выводит попадания/выстрелы по обоим типам. После PPO fine-tuning и
30-эпохового ranged behavior-cloning детерминированный прогон на 1 000 боях показал
531 выстрел/323 попадания из лука и 358/356 из арбалета; исходный actor на той же
конфигурации не стрелял. Финальный checkpoint: `models/terrain_finetune/pvp_ppo_terrain_multi_aggressive_bow_crossbow_25k_bc30.zip` (локальный артефакт,
исключён из Git существующим `.gitignore`). Его веса экспортированы в `ppo_policy.bin`
и сверены с SB3 без расхождений по действиям. JAR пересобирается через GitHub Actions;
обновлённый артефакт показывает имя `AI Pilot 7 — авто-бой` и версию `1.0.7`. Живой
бой в Minecraft пока не проверен.

## Отдельный клиентский Forge-мод: AI Pilot 7 (Minecraft 1.16.5)

Это самостоятельный Java-мод для клиента Minecraft Forge 1.16.5 (Forge 36.2.39),
подключённый к 52-признаковому multi-opponent PPO-актору
`models/terrain_finetune/pvp_ppo_terrain_multi_aggressive_bow_crossbow_25k_bc30.zip`.
Экспортированные веса лежат внутри исходного Forge-ресурса (`ppo_policy.bin`); инференс
выполняется на чистом Java-коде, поэтому Python/PyTorch и интернет во время игры не
нужны. Поставляемый JAR собирается в GitHub Actions; таблица признаков и ID действий,
ограничения Forge-исполнения и неподтверждённые live-сценарии описаны в
[`forge-mod/PPO_INTEGRATION.md`](forge-mod/PPO_INTEGRATION.md). Нужные предметы
ищутся по всему инвентарю и при закрытом интерфейсе штатно меняются с хотбаром;
это не заменяет проверку реального боя на сервере.

### Установка

1. Установи Minecraft **1.16.5** и Forge **36.2.39**.
2. Скопируй `aipilot-1.16.5.jar` в папку `mods` именно того игрового профиля/каталога,
   с которым запускаешь Forge.
3. Запусти игру через профиль Forge. Мод ставится **только на клиент**.

### Управление

- **O** — включить или выключить PPO-автобой.
- **J** — показать или скрыть HUD; HUD показывает ID последнего действия модели.

Когда автобой включён, мод собирает 52 признака локального боя и толпы, выполняет
детерминированный Java-инференс multi-opponent PPO-актора и применяет одно из 30 действий
10 раз в секунду. Он ищет живую цель в радиусе до 17 блоков (кроме стоек для брони
и игроков в Creative/Spectator). Vanilla-клиент не может точно наблюдать некоторые
симуляторные признаки и не воспроизводит custom arena-комбо; соответствия и
ограничения описаны в `forge-mod/PPO_INTEGRATION.md`. Если веса отсутствуют или
не читаются, автобой fail-closed и эвристика не запускается.

Мод использует уже запущенную клиентскую сессию и обычные действия Minecraft; он не
просит пароль и не реализует отдельный вход в аккаунт. На публичных серверах автоматизация
может нарушать правила или блокироваться античитом — используй автобой только там,
где это разрешено.

## Папки с готовыми модами

Установочные файлы собраны в [`mods/`](mods/): PvP-клиент — в `mods/pvp/`, нейросетевой Minecraft datapack — в `mods/build/`. В каждой папке есть инструкция установки. Исходники оставлены в `forge-mod/` и `builder/`, чтобы не ломать сборку и обучающие команды.

## Живой сервер + спектатор

```bash
node bot/mock_server.js                     # MC 1.16.5 на :25565 + дашборд 0.0.0.0:8080
STEP_DELAY_MS=75 node bot/bot.js            # LearnerBot + профессиональный EnemyBot
.venv/bin/python play.py --mode live --model models/pvp_ppo_pro_500k.zip --episodes 300
```

Дашборд `:8080` показывает 8 камер 360° вокруг обоих ботов, полосу HP, щиты, броню,
поставленные блоки и живой лог боя (включая `💥 Explosion`, `⚡ W-TAP`, `🧱 OBSIDIAN CAGE`).
На телефоне открой Live Preview порта `8080`: страница адаптируется к экрану, а камеру
можно выбрать из списка; соединение с ареной обновляется по WebSocket.
В демонстрационном live-режиме `PPO COMBO FINAL` играет против PRO-противника со
скриптовой тактикой (это не матч двух PPO-сетей).

## Комбо-механика (второй этап, +500 000 боёв)

Добавлены две новые механики и два новых действия (`28` — выход из комбо, `29` — контр-комбо):

* Серия ударов по одной цели копит **цепочку**: каждый следующий удар бьёт сильнее
  (`+6%`, максимум `+40%`), а оглушённый боец не может ответить (`0.45 с`).
* Выход из комбо сбрасывает цепочку, даёт неуязвимость и открывает окно контратаки.
* Противник во время обучения специально «звереет» (агрессия 0.55 → 1.0), а 45% боёв
  начинаются сразу внутри цепочки — иначе учиться выходить было не на чем.

Результат финального прогона (501 207 боёв, 26.7M шагов):

| Метрика | PRO 500k (было) | COMBO FINAL |
|---|---|---|
| Выходов из комбо | 0 | **122 374** |
| Контр-комбо | 0 | **4 230** |
| Win-rate в бенчмарке | 76.8% | 74.4% |
| Выходов из комбо на бой | 0.00 | **0.57** |

## Результаты

* **500 694** живых боя за 24 минуты (~350–700 боёв/с), 20 447 232 шага PPO.
* Win-rate против профессионала вырос с **3%** (старт) до **88%** (последние 200 боёв).
* С комбо-механикой финальный прогон держит **74.4%** против уже усиленного
  (агрессия 1.0, 45% боёв начинаются внутри цепочки) противника.
* Итоговый бенчмарк модели, 400 боёв на каждый уровень скилла:
  `skill 0.30 → 80.6%`, `0.60 → 78.4%`, `0.85 → 77.7%`, `1.00 → 77.2%`.
* **Второй этап (+500 000 боёв)**: 501 207 боёв, 26.7M шагов — агент научился выходить
  из комбо (122 374 раза) и ставить контр-комбо (4 230 раз), см. таблицу выше.
* Живой сервер (12 боёв): **75.0% побед** (`9W / 3L / 0T`), MeanReward `66.3`, MeanSteps `55.2`.
* Приёмы в живых боях: `obsidian_cage 19`, `cobweb_trap 7`, `end_crystal 3`, `pearl_crystal 2`,
  `tnt_minecart 1`, `respawn_anchor 1`, `wtap_combo 1`, `pillar_jump 5`, `lava_trap 3`,
  `crossbow 4`, `buff_potion 4`.

## Поиграть самому (браузер)

Сырой порт Minecraft `25565` из песочницы наружу не пробрасывается, поэтому для игры
с человеком есть отдельная браузерная арена — тот же движок боя, что и в обучении:

```bash
.venv/bin/python human_server.py --port 8090 --model models/pvp_ppo_combo_final.zip --level normal
```

Открыть `http://localhost:8090` — вид сверху, кнопки действий и управление с клавиатуры
(`WASD`, пробел, ЛКМ/E, Shift, 1–9, **R** — выйти из комбо, **T** — контр-комбо). Ты играешь за второго бойца, нейросеть — за первого.

| Уровень | Что делает гандикап |
|---|---|
| Лёгкий  | у ИИ 12 HP вместо 20, и он действует через ход |
| Обычный | у ИИ 17 HP вместо 20 |
| Про     | без гандикапа — так, как она играла 1 000 000 боёв |

API: `GET /api/state`, `POST /api/action {"action": N}`, `POST /api/level {"level": "easy|normal|pro"}`,
`POST /api/reset`. Все 28 действий описаны в `web/play.html` (массив `PAD`).
